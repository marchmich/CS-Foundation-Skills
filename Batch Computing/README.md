### Project: Computational Scaling and Performance Analysis  

#Description:
In this assignment, I worked with parallel computing concepts using provided programs (`auc-trapazoidal-serial.c` and `primes.c`) to analyze their performance and scaling based on different input parameters. I explored how varying parameters like `a`, `b`, and `n` impacted execution time. After identifying parameter values that resulted in approximately one hour of execution on computing clusters like Hamilton or Whedon, I validated the program's correctness and submitted jobs using the Slurm workload manager.

**Tools and Techniques Used:**  
- **Programming Language:** C    
- **Workload Manager:** Slurm (using `sbatch` for job submission)  
- **Timing Execution:** `time` command in Unix/Linux  
- **Experimentation and Analysis:** Parameter tuning to assess computational scaling and performance  

This project provided hands-on experience in program execution on high-performance computing clusters, performance timing, and job scheduling in a distributed computing environment.
