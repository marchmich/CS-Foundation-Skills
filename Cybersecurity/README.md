### Project: Network Traffic Analysis and Security Concepts Writeup  

**Description:**  
For this assignment, I performed advanced network monitoring and analysis on the Bowie CS server. Using **tcpdump**, I captured and analyzed two types of network traffic:  
1. **Ping Traffic:** Monitored ICMP echo requests and responses to study the behavior of packet transmission between hosts.  
2. **Web Traffic:** Examined HTTP/HTTPS packets, including headers and payload information, to identify data flow and possible patterns.  

Additionally, I conducted an in-depth investigation of a given IP address, detailing its:  
- Route  
- DNS name and server  
- Ownership information, including the registered street address  

The task involved obtaining administrative permissions and using precise commands to ensure meaningful packet capture and accurate interpretation of network traffic.  

In the second part, I created a comprehensive Markdown-based writeup of key security concepts, providing definitions, examples, and real-world applications for terms like **social engineering**, **firewalls**, and **encryption**. The writeup also included an analysis of vulnerabilities (e.g., **buffer overflow**, **race conditions**) and best practices (e.g., **two-factor authentication**, **password managers**). Finally, I addressed the question of **VPN usage**, discussing the trade-offs and considerations when deciding to use or forego a VPN.

---

**Tools and Techniques Used:**  
- **Network Monitoring:** `tcpdump` for live traffic capture and analysis  
- **IP Investigation:** Tools like traceroute, dig, and WHOIS for IP information retrieval  
- **Security Research:** Understanding and explaining key security concepts and vulnerabilities  
- **Documentation:** Markdown for clear, organized, and formatted writeups  

---
This assignment enhanced my understanding of network protocols and tools for traffic analysis. I learned how to interpret ICMP and web traffic using **tcpdump**, gaining insight into packet structures and flow.
